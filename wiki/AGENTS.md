# Versioned Wiki guides

This directory contains reviewed guides for operators and contributors. The
live GitHub Wiki links to these guides and owns its separate help pages and
stable deep links.

Follow the documentation style rules. Keep links to branch policy in
`BRANCHING.md`, status in `PROJECT_STATUS.md`, and operational details under
`docs/operations/`. Confirm button names and settings against the current
application when updating operator instructions. Document feature availability
by release or branch when it differs from the installed stable version.

Use the normal pull request to develop for tracked guides. Verify affected
Markdown links and current live Wiki destinations. Preserve existing help
paths and anchors used by the application. Keep private evidence, credentials
and generated artifacts out of these guides.
